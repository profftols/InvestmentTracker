# 🗺️ Roadmap проекта InvestmentTracker

## 🏗️ Phase 0: Фундамент и Инфраструктура
Цель: Настроить проект, БД и CI/CD окружение.

- [x] Создать Solution и проекты по Clean Architecture (Api, Application, Domain, Infrastructure).
- [x] Настроить .gitignore для скрытия секретов.
- [x] Поднять PostgreSQL (локально или в Docker).
- [x] Настроить подключение к БД в `appsettings.json` (с учетом удаленной работы).
- [ ] **Написать `ApplicationDbContext` и настроить Entity Framework Core.**
- [ ] Создать и применить первую миграцию (создание таблиц в БД).
- [ ] Настроить Swagger для удобного тестирования API.

## 📱 Phase 1: MVP (Ручной учет)
Цель: Научиться создавать счета и записывать, сколько денег я вложил ("Мои кровные").

- [ ] **Реализовать CRUD для Счетов (Accounts):**
    - [ ] Создание счета (например, "Сейф дома", RUB).
    - [ ] Получение списка счетов.
- [ ] **Реализовать CRUD для Операций (Transactions):**
    - [ ] Метод "Пополнить счет" (Deposit).
    - [ ] Метод "Вывести со счета" (Withdraw).
- [ ] **Базовая логика (Application Layer):**
    - [ ] Сервис расчета `TotalInvested` (Сумма пополнений - Сумма выводов).
    - [ ] Валидация (нельзя пополнить на отрицательную сумму).

## 🔌 Phase 2: Интеграции (T-Bank & Bybit)
Цель: Автоматически подтягивать "Текущий баланс" с бирж.
*Архитектурный момент:* Создать интерфейс `IExchangeProvider`, чтобы система не зависела от конкретной биржи.

- [ ] **Интеграция с T-Bank:**
    - [ ] Получить токен (Sandbox/Combat).
    - [ ] Реализовать провайдер для получения суммы портфеля (Акции + Облигации + Кэш).
- [ ] **Интеграция с Bybit:**
    - [ ] Изучить подпись запросов (HMAC SHA256).
    - [ ] Реализовать получение баланса Unified Trading Account.
- [ ] **Конвертация валют (Currency Service):**
    - [ ] Реализовать механизм приведения всего к одной валюте (например, сколько стоит мой BTC в рублях по текущему курсу).

## 🤖 Phase 3: Автоматизация и История
Цель: Собирать данные, пока я сплю, чтобы строить графики.

- [ ] **База данных:**
    - [ ] Создать сущность `PortfolioSnapshot` (Дата, IdСчета, СуммаВРублях, СуммаВДолларах).
- [ ] **Фоновые задачи (Background Jobs):**
    - [ ] Подключить Hangfire или Quartz.NET.
    - [ ] Написать джобу `UpdatePortfolioJob`:
        1. Пройтись по всем счетам.
        2. Если авто-счет -> запросить API.
        3. Если ручной -> взять текущий баланс из базы.
        4. Сохранить снимок в БД.

## 📊 Phase 4: Аналитика и Финансы (Твои спец. требования)
Цель: Понимать, богат я или беден.

- [ ] **Расчет доходности:**
    - [ ] Формула: `(ТекущаяСтоимость - Вложено) / Вложено * 100%`.
    - [ ] Расчет PnL (Profit and Loss) в абсолютных числах (+15 000р).
- [ ] **Сегментация (Crypto vs Fiat):**
    - [ ] Группировка активов: "Сколько всего в крипте" vs "Сколько в банках".
    - [ ] Аналитика по валютам: "Доходность долларовой части портфеля".
